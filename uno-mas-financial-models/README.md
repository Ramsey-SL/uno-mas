# Uno Más — Financial Models

Deal-structuring and exit-planning work for Uno Más Monroe Street: sale scenarios,
seller-note structures, the landlord JV / debt-consolidation plan, and every artifact
produced along the way. This section exists because that work was previously living only
inside chat sessions and a session-local scratchpad — neither of which persists. Start
here in any new session.

## Start here

**`HANDOFF-EXIT-AND-JV-PLANNING_2026-09-05.md`** — the full pickup document. Covers:
- The debt picture (source of truth: cross-check against the SBA-Capital-Readiness Drive
  folder's `Debt/Uno Mas - DEBT SCHEDULE.csv`, which remains the canonical live figures)
- Plan A — sale to a third-party buyer (pricing ladder, seller-note terms, the
  Amex/Chase distinction, asset-vs-equity-sale tax exposure)
- Plan B — landlord JV + SBA debt consolidation + event-space venture (the more
  recently developed, more complete plan)
- SBA FOIA findings on both MoFi loans (guaranty %, true maturity)
- Open items and immediate next actions

## `artifacts/`

Local copies of the HTML source for artifacts published during this work, where the
source was still available to copy. The published, hosted versions are the authoritative
copies — links are in the handoff doc — these local copies are a backup in case a hosted
artifact is ever lost, and so the design/data can be edited and republished from a fresh
session without reconstructing everything from scratch.

| File | What it is |
|---|---|
| `landlord-pitch.html` | Plan B pitch for the landlord — the most current deliverable |

Four earlier artifacts (the broker operating summary, the buyer deal-terms one-pager, the
earlier investor/partner memo, and the June 2026 bank statement) exist only as hosted
artifacts — their local source was already cleaned up before this folder was created.
Their links are in the handoff doc; if you need to edit one, use the Artifact tool's
`read` action on its URL to pull the current published HTML back down first.

## Source of truth stays in the Drive folder

This repo section is for planning documents, models, and artifacts — not for primary
financial records. Bank statements, the debt schedule, tax returns, and POS data remain
in the ProtonDrive `SBA-Capital-Readiness/01_Uno_Mas` folder. When a figure here
disagrees with that folder, the Drive folder wins; update this doc, not the other way.
