# Campaign Web Design Packages — plan + format

Each campaign gets a **web design package**: everything needed to build its site presence in Lovable
(or hand to an editor). A package contains:
1. **Placement** — standalone page vs homepage section vs menu callout (+ route).
2. **Layout / wireframe** — sections top-to-bottom.
3. **Final copy** — headline, body, CTA (from the campaign's `creative-copy.md`).
4. **Imagery** — specific DAM assets (Cloudinary URLs / tags) for each slot.
5. **Brand treatment** — palette + fonts (Uno Más warm, or Mezzanine pink/black).
6. **Lovable build prompt** — paste-ready natural-language spec.
7. **CTA wiring** — Resy / Toast / Klaviyo / reservation link.
