## Publish steps (from the Uno Más Page)
1. **Meta Business Suite / Facebook Page → Events → Create event → In person.**
2. Name, cover image (`poster-final.png`), location, **set recurring → Weekly → Thursdays**, pick the 3 dates.
3. Set start 5:00 PM / end 9:00 PM Pacific; description (above); **Add ticket/registration link → Resy URL.**
4. Set **21+**, add co-hosts if a tequila sponsor signs on, add keywords.
5. Publish. Create **Event B (Finale)** as a separate one-time event.
6. **Cross-post:** share each event to the Page feed Thursday AM (pair with the reminder post in `creative-copy.md`),
   add the event link to the IG/TikTok bio alongside the Resy link, and pin the announcement post.
