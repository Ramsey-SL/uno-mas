Daily Special Banners

One tile per day · same structure as the live Taco Tuesday tile
Built as a series, deliberately. Same torn flyer, same pink-lead + yellow-supporting boxes, same useIsSpokaneDay(day) gate. Only the day name and the offer change. That's the point — a guest who learns the shape once can read any day at a glance, and it makes the specials feel like a programme rather than five unrelated promos.
Every tile reuses the hook that already ships — no new gating code, just a different day index.
⚠️ Two things to decide, flagged on the relevant tiles: whether Friday/Saturday shows a tonight-only 8–10pm offer all day, and whether Sunday needs a tile at all given the homepage already has a brunch feature band.

Two decisions before I ship these.
1 · Friday/Saturday. Late Night is 8–10pm only. Options: (a) show it all day with the "Tonight · 8–10PM" badge as mocked — simple, reads fine at noon; (b) add a time gate so the tile only appears from ~4pm — more honest at 11am, but it means extending the hook to take an hour range; (c) don't run a Fri/Sat tile at all and let the menu carry it. I'd take (b) — the hook is already built and an hour range is a small addition, and a "tonight" promise at lunchtime is weaker than the same promise at 5pm.
2 · Sunday. The homepage already has a brunch feature band. I'd skip the Sunday tile and instead have the weekday gate hide the brunch band on non-Sundays if it isn't already — one strong block beats two competing ones. Also worth confirming those three brunch prices, since I pulled them from the menu doc rather than a current print menu.
