# Local Listings Asset Kit

> **Purpose:** everything needed to keep Google Business Profile, Apple Business Connect, Yelp,
> Bing Places, TripAdvisor, Resy and the social profiles current — photos, videos, menus, promos,
> and copy-paste text — in one place.
>
> **Build the upload folder:** `bash scripts/build-listings-kit.sh`
> It downloads a dated, ready-to-upload folder with per-platform crops generated by Cloudinary.
> No manual resizing.
>
> Last verified: 2026-08-21

## 3. Per-platform image specs

Cloudinary generates every crop on demand, so one source asset serves all platforms.
**Verify current specs on each platform before a big upload — they change.**

| Platform | Asset | Target | Cloudinary transform |
|---|---|---|---|
| **Google Business Profile** | Logo | 720×720 (1:1) | `c_fill,g_auto,w_720,h_720,q_auto,f_jpg` |
| | Cover | 1024×576 (16:9) | `c_fill,g_auto,w_1024,h_576,q_auto,f_jpg` |
| | Additional | 1200×900 (4:3) | `c_fill,g_auto,w_1200,h_900,q_auto,f_jpg` |
| **Apple Business Connect** | Logo | 1080×1080 | `c_fill,g_auto,w_1080,h_1080,q_auto,f_jpg` |
| | Hero | 1920×1080 | `c_fill,g_auto,w_1920,h_1080,q_auto,f_jpg` |
| **Yelp** | Photos | 1600px wide min | `c_limit,w_2000,q_auto,f_jpg` |
| **Facebook** | Cover | 1640×624 | `c_fill,g_auto,w_1640,h_624,q_auto,f_jpg` |
| **Instagram / social** | Feed 4:5 | 1080×1350 | `c_fill,g_auto,w_1080,h_1350,q_auto,f_jpg` |
| | Story 9:16 | 1080×1920 | `c_fill,g_auto,w_1080,h_1920,q_auto,f_jpg` |

Add the **house grade** to every delivery: `e_saturation:18,e_contrast:10,e_brightness:4`.
Videos use `c_fill,g_center`; images `c_fill,g_auto`.

## 5. ⚠️ Cautions

1. **`needs-hires-swap`** — ~141 Cloudinary assets are 2048px shared-album derivatives. Fine for
   listings and social; **not** for print or large format. The shortlist above avoids them.
2. **Naming-convention violations.** 31 assets in live use have non-conforming public_ids
   (`IMG_0245`, `2R7A8526`, `carne-asada-knife-hero`, …). They work, but they're unsearchable by
   the `YYYYMMDD_UM_CATEGORY_Subject_v#` convention. Worth a rename pass.
3. **🔴 Schema.org `logo` is wrong.** The site's Organization JSON-LD sets
   `logo: 20251217_UM_VENUE_VenueInterior_FINAL_11` — an *interior photo*, not a logo. Google uses
   this for knowledge-panel branding. Should point at an actual logo from
   `uno-mas/approved-assets/logos`. **Fix on the site.**
4. **NAP consistency is the whole game** for local SEO. If you change the name in one place, change
   it everywhere in the same sitting.
