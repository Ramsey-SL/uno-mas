# Uno Más — Words, Phrases to Use and Avoid

## The Master Forbidden List

These words and phrases are never used in any Uno Más or Mezzanine content — not in captions, emails, SMS, review responses, menus, or marketing copy. If AI generates them, delete them.

| Forbidden | Why It's Banned |
|---|---|
| Mouthwatering | Every restaurant says this. It says nothing. |
| Artisanal | Overused to the point of meaninglessness. |
| Authentic Mexican | Reductive, imprecise, and not what we are. |
| Curated | Corporate. Nobody curates tacos. |
| Elevate / Elevated | Pretentious. The food elevates itself. |
| Utilize | Just say "use." |
| Leverage | Wrong context entirely. |
| Refreshing | Every drink company uses this. We don't. |
| Tantalizing | No. |
| Delectable | No. |
| Mixology | We have a bar. We have bartenders. That's it. |
| Culinary journey | We're not a fine dining destination with a narrative arc. |
| We are excited to announce | The excitement is in the thing, not the announcement. |
| Unforgettable experience | Every venue says this. Say what the experience actually is. |
| State-of-the-art | Wrong register entirely. |
| We strive to | Used in apology language. Replace with action. |
| We apologize for any inconvenience | Always too corporate. Say something real instead. |
| Indulge / Indulge yourself | Overwrought. |
| Savory | Vague food descriptor. Name the ingredient instead. |
| Robust | Same problem. Specific beats vague. |
| Flavorful | If you need to say it's flavorful, the description failed. |
| Unique | Everything is unique. Find the actual differentiator. |
| Vibrant | Restaurant cliché. |
| Nestled | Travel writing cliché. We're on Monroe. |
| Delight / Delightful | Too gentle for this brand. |

## Words That Are Always Correct

These are safe, on-brand word choices for any context:

- **crispy, charred, melted** — food texture descriptors that are specific and real
- **braised, smoked, grilled** — cooking method descriptors (accurate only)
- **consomé, cotija, crema, tajin, chamoy** — specific ingredient names (accurate only)
- **tequila blanco, reposado, añejo** — specific spirit references
- **DM us** — preferred over "message us" or "reach out"
- **come in** — preferred over "visit us" or "stop by"
- **your crew / your group** — preferred over "guests" or "patrons"
- **the team** — preferred over "our staff" or "our employees"
- **the patio / the main floor / the cantina / the Mezzanine** — use the actual space names
- **Neon Tacos** — always capitalize, always use full name for loyalty program references

## Phrases to Use in Negative Review Responses Only

These are service recovery phrases — do not use them in marketing:

- "That's not the experience we wanted for you."
- "We'd genuinely like to make it right."
- "That's not who we are on a normal night."
- "We're looking at this — thank you for being honest."
- "Ask for [name] next time you're in."

---

## Phrases to Never Use in Review Responses

| Never say | Say instead |
|---|---|
| "We apologize for any inconvenience" | "That's not the experience we wanted for you" |
| "We strive to provide excellent service" | [Just respond with action — not a policy statement] |
| "We will take your feedback into consideration" | "We're looking at this — thank you for being honest" |
| "Please reach out to our team" | "Call us at (509) 960-7989 / ask for [name]" |
| "Thank you for your feedback" [alone] | Always pair with something specific |
| "We hope to see you again soon!" | Make the invitation specific — item, event, time |

## SMS-Specific Language Rules

- Begin messages with "Uno Más:" — this identifies the sender immediately
- End every SMS with "Reply STOP to opt out." — required for TCPA compliance
- Use contractions freely (we're, you'll, it's) — SMS is casual
- Use numerals for prices and times ($12, 3pm) — saves characters
- No em dashes in SMS — use a period or line break instead

## Emoji Usage

### Approved Core Set
`👀` `🌮` `✨` `💙` `🍹` `🔥` `🎉` `☀️` `🪩`

### Rules
- 0–5 per social post — never decorative padding
- 0–2 per SMS — never use just for filler
- 0–1 per review response — `💙` and `🌮` are the right ones here
- Emojis should add meaning. If you can remove it and lose nothing, remove it.
- Never use emojis in formal or professional contexts (event proposals, Mezzanine packages)
