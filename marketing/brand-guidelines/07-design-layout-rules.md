# Uno Más — Design and Layout Rules

## Overview

All Uno Más and Mezzanine designed assets are produced in Canva using the brand-specific kits. These rules apply to social graphics, email headers, promotional assets, event flyers, and any other visual output.

---

## Uno Más — Layout Rules

### Brand Kit
**Canva Kit ID:** `kAFqKpAzOh0`
**Fonts:** Antonio (display) + Montserrat (body)
**Colors:** Pink `#E22690` / Blue `#18BCDC` / Navy `#003366` / Yellow `#FFEC00`

### Core Layout Principles

**1. One focal point per design.**
Every piece should have one thing the eye goes to first. If two elements are competing for attention, one of them needs to go. Headlines or food photography — pick the hero, support everything else.

**2. Hierarchy is non-negotiable.**
The most important information (item name, deal, CTA) must be visually dominant. Supporting information (details, hashtags, fine print) must be clearly subordinate. If everything is the same size, nothing is important.

**3. Breathing room.**
More white (or color) space is almost always better. Don't crowd the layout. Negative space makes the focal element hit harder.

**4. Text on photography.**
If text overlays a photograph, ensure minimum 4.5:1 contrast ratio. Use a semi-transparent dark or light overlay band if needed. Never place colored text directly on a busy photo without a text treatment.

### Social Media Sizing (Uno Más)
| Format | Dimensions | Use Case |
|---|---|---|
| Feed Post (Portrait) | 1080 × 1350px | Primary Instagram feed format |
| Feed Post (Square) | 1080 × 1080px | Alternate feed format |
| Story / Reel Cover | 1080 × 1920px | Instagram Stories, Reels thumbnail |
| Facebook Post | 1200 × 630px | Facebook feed |
| Email Header | 600 × 200px | Klaviyo email header |

### Color Usage in Layout
- Pink `#E22690` as the primary CTA button, primary headline, or key accent — never used as a background behind body text
- Blue `#18BCDC` as secondary accent — icons, borders, secondary CTAs
- Navy `#003366` as the preferred dark background color or body text color on light backgrounds
- Yellow `#FFEC00` as a highlight only — never for body text, never for large background fills
- White backgrounds should be off-white (`#FAFAFA`) to avoid harsh glare on screen

### Button / CTA Design
- CTA buttons: Pink fill, white text, Montserrat Bold, rounded corners (4–8px radius)
- Secondary CTA: Navy outline, Navy text, no fill
- Minimum button width: 160px; minimum height: 44px (touch target)
- Button text: 5 words or fewer

## The Mezzanine — Layout Rules

### Brand Kit
**Canva Kit ID:** `kAGze1MPDmA`
**Fonts:** DIN Condensed (display) + Poppins (body)
**Colors:** Electric Pink `#E22790` / Ultra Violet `#93009B` / Black `#000000`

### Core Layout Principles

**1. Dark backgrounds dominate.**
Black is the canvas. Every Mezzanine asset should feel like it's emerging from darkness. Light-on-dark is the default direction — never reverse it for standard layouts.

**2. Less is more.**
The Mezzanine brand communicates through restraint. One or two lines of copy. One strong image. Nothing extra. If an element doesn't earn its place, it's gone.

**3. Drama through contrast.**
Electric Pink on black creates maximum visual impact. Use this contrast deliberately — not as decoration, but as the signal that something important is here.

**4. Typography as atmosphere.**
DIN Condensed set in all caps, large, in Electric Pink on a black background is itself the design. Don't over-layer with graphic elements — let the type do the work.

### Social Media Sizing (Mezzanine)
Same dimensions as Uno Más (1080 × 1350px primary, 1080 × 1920px for Stories). Dark treatment applied throughout.

### What to Never Do in Mezzanine Design
- No Yellow — it breaks the dramatic palette entirely
- No bright or white backgrounds
- No loud, high-energy graphic elements (stars, confetti, loud patterns)
- No Uno Más pink (`#E22690`) — use Mezzanine pink (`#E22790`)
- No more than two typeface families in a single piece
- No gradients from pink to yellow — that's Uno Más energy

## Universal Design Rules (Both Brands)

### What Both Brands Share
- Clean, intentional layouts — never cluttered
- Typography-first philosophy — words are design elements
- Photography as the primary selling tool — the food and space sell themselves
- No clip art, stock illustration, or generic graphic elements

### File Export Standards
| Use Case | Format | Resolution |
|---|---|---|
| Instagram / Facebook | PNG or JPG | 72dpi, full pixel dimensions |
| Email header | JPG | 72dpi, 600px wide |
| Print (flyers, menus) | PDF | 300dpi, with bleed if applicable |
| Canva share link | Use "Publish as Link" | For internal review only |

### Approval Before Publishing
All designed assets should be reviewed against these criteria before publishing:
- [ ] Correct brand kit used (Uno Más vs Mezzanine)
- [ ] Correct fonts applied
- [ ] No forbidden words in any text element
- [ ] Logo present and correctly placed (when required)
- [ ] Price included only when content is explicitly promotional
- [ ] Address included only in paid ads, email, SMS, or first-visit discovery contexts
- [ ] Text contrast ratio passes 4.5:1 minimum

### What Does Not Need Design
Not every post needs a designed graphic. Photos of real food and real atmosphere consistently outperform designed templates on organic social. Reserve designed assets for:
- Promotional announcements (deals, events, new items)
- Stories with text overlays
- Email headers
- Paid advertising creative
- Print materials
